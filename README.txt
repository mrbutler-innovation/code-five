CODE FIVE - Agency Terminal Wrapper

Files:
- index.html      Custom Agency launch/player page
- style.css       Visual styling
- CODE_FIVE.html  Your exported Adventuron game

GitHub setup:
1. Rename your currently-hosted Adventuron index.html back to CODE_FIVE.html.
2. Upload this new index.html and style.css to the repository root.
3. Keep CODE_FIVE.html in the same repository root.
4. GitHub Pages will automatically use the new index.html as the landing page.

Repository layout:
code-five/
  index.html
  style.css
  CODE_FIVE.html

No changes are required inside CODE_FIVE.html.
